The standard action control; `primary` for the single main action per screen, `accent` only for warm secondary CTAs.

```jsx
<Button variant="primary" size="lg" iconLeft="plus" fullWidth>Registrar gasto</Button>
```

Variants: primary · accent · secondary · soft · ghost · danger. Sizes sm/md/lg map to 36/44/52px — md and up satisfy the 44px tap target. Press state shrinks to 0.97.
