Every money figure in the product. Never format amounts by hand.

```jsx
<Amount value={2450000} size={40} tone="neutral" />
<Amount value={-38900} size={17} tone="expense" showSign />
```

es-CO thousands separators, tabular numerals, currency symbol and decimals at 62% size / 60% opacity. Colour alone never carries meaning — pair with `showSign` or an icon.
