# UI kit — Reporte PDF

Especimen del documento descargable. A4 vertical, márgenes 18mm, misma paleta y tipografía que la app.

- **Portada** (solo reportes anuales): fondo crema, isotipo grande, título en Piazzolla 40px, hogar y periodo.
- **Encabezado**: banda `--cc-bg` con el logo horizontal a la izquierda y el tipo/rango/hogar a la derecha.
- **KPIs**: 3–4 tarjetas, borde 1px, radio 12px, cifra 24px tabular, etiqueta 10px mayúsculas .08em.
- **Tablas**: encabezado `--cc-primary-soft`, filas alternas `--cc-surface-alt`, montos a la derecha en tabular-nums, chip de color por categoría, sin bordes verticales.
- **La Escalera** rasterizada; la tabla numérica va como anexo en la página siguiente.
- **Pie**: línea 1px, generado / tagline / página X de Y.
- **Marca de agua**: isotipo al 45% del ancho, rotado −22°, primario al 5%. Variantes "BORRADOR" y "CONFIDENCIAL" en el display a 64px al 7%.
