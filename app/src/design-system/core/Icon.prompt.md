Lucide glyph at the brand stroke weight (1.75); use it for every icon in the product instead of hand-drawn SVG.

```jsx
<Icon name="piggy-bank" size={20} color="var(--cc-savings)" />
```

Names are Lucide kebab-case. Copies of the 50 most-used glyphs also live in `assets/icons/` for offline/PDF use.
